
# 🎬 Movie Review Sentiment Analysis



Welcome to **Movie Review Sentiment Analysis** (CineSentiment AI), a web application that predicts the sentiment (positive or negative) of movie reviews using a deep learning model. Built with Streamlit and TensorFlow, this app leverages an LSTM model trained on the IMDB dataset to provide accurate sentiment predictions with confidence scores. Deployed on Streamlit Cloud, it's user-friendly and perfect for movie enthusiasts and developers alike! 🎥

---

## 🚀 Features

- **Sentiment Prediction**: Analyze any movie review and get instant sentiment predictions (Positive/Negative) with confidence scores and progress meters.
- **Interactive UI**: Clean horizontal radio menu to navigate seamlessly between the Home overview and Prediction pages.
- **Example Reviews**: Try pre-loaded reviews directly on the main prediction page with a single click.
- **Batch CSV Processing**: Upload CSV files containing movie or social media reviews (e.g., Xquik/Tweet exports) to process up to 50 reviews simultaneously with downloadable CSV reports.
- **Analysis History & Export**: Keep track of review history during your session and export full logs as Markdown files.
- **Modern Responsive UI**: Custom CSS styling with clean custom HTML cards without raw code snippet glitches.

## 🛠️ Setup and Installation

### Prerequisites
- Python 3.10 or higher
- Git
- Streamlit Cloud account (for deployment)
- Jupyter Notebook (to run the training script)

### Local Setup
1. **Clone the Repository**:
   ```bash
   git clone [https://github.com/rohanmistry231/sentiment-analysis-app.git](https://github.com/rohanmistry231/sentiment-analysis-app.git)
   cd sentiment-analysis-app

```

2. **Install Dependencies**:
Create a virtual environment and install the required packages:
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt

```


3. **Prepare Model Files**:
The app requires `model.h5` and `tokenizer.pkl` to function. These files are generated by training the model using the provided Jupyter Notebook:
* Open `IMDB_reviews_Sentiment_Analysis_LSTM.ipynb` in Jupyter Notebook.
* Run all cells to train the LSTM model on the `IMDB_Dataset.csv` dataset.
* The notebook will save `model.h5` (the trained model) and `tokenizer.pkl` (the tokenizer) in the project root.


**Note**: If you already have pre-trained `model.h5` and `tokenizer.pkl` files, you can skip this step.
4. **Run the App Locally**:
```bash
streamlit run app.py

```


Open your browser and go to `http://localhost:8501`.

## 🌐 Deploy on Streamlit Cloud

1. **Push to GitHub**:
* Create a new repository on GitHub.
* Push your project files:
```bash
git add .
git commit -m "Initial commit"
git push origin main

```




2. **Set Up Streamlit Cloud**:
* Log in to [Streamlit Cloud](https://streamlit.io).
* Click "New App" and connect your GitHub repository.
* Select the branch (e.g., `main`) and specify `app.py` as the main file.
* Click "Deploy".


3. **Verify Deployment**:
* Once deployed, Streamlit Cloud will provide a public application URL.

## 📖 Usage

1. **Navigate the App**:
* Use the top navigation bar to toggle between the **Home** workflow overview and the **Analyze** page.


2. **Analyze Individual Reviews**:
* Write or paste a review into the review input area and click **✨ Analyze Sentiment**.
* Review predictions and confidence scores rendered instantly.


3. **Quick Try with Examples**:
* Click **Analyze Example** under any pre-loaded card (Positive, Negative, Mixed) on the page to run test evaluations.


4. **Batch Analyze CSV Files**:
* Upload a CSV file (5 MiB limit, max 50 rows).
* The app automatically parses columns like `Tweet Text`, `review`, `text`, or `comment`.
* View summary metrics and click **⬇️ Download CSV Results** to save analyzed output.


5. **Session History & Export**:
* View past results directly in the **Analysis History** card log.
* Click **📥 Export History (Markdown)** to save session logs or **🗑️ Clear History** to start fresh.

## 🧠 Model Details

* **Dataset**: IMDB dataset of 50,000 movie reviews (`IMDB_Dataset.csv`).
* **Model Architecture**: Sequential LSTM network using Keras/TensorFlow.
* **Preprocessing**: Custom text cleaning, tokenized via Keras Tokenizer, padded to a sequence length of 200.
